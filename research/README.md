# Research materials

This directory keeps the original notebooks and source material that document
the training and evaluation workflow. They are retained for provenance; the
current execution path is implemented as Python scripts under `../src/`.

The archived notebooks retain some of their original local or Colab paths and
should be treated as research records rather than turnkey scripts.

`legacy/` contains the earlier notebook script copy, duplicate visual exports,
and intermediate figures moved out of the active repository tree.
It is ignored by Git so the published checkout stays focused on the canonical
assets and source files while the local originals remain recoverable.
