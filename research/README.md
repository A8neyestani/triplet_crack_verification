# Research materials

This directory keeps the original notebooks and source material that document
the training and evaluation workflow. They are retained for provenance and are
not required to regenerate the motion graphic.

The canonical, portable renderer is [`../src/generate_motion_graphic.py`](../src/generate_motion_graphic.py). The historical notebooks retain some of
their original local or Colab paths; they should be treated as archival
research records rather than turnkey scripts.

`legacy/` contains the original duplicate motion export, the earlier notebook
script copy, and intermediate figures moved out of the active repository tree.
It is ignored by Git so the published checkout stays focused on the canonical
assets and source files while the local originals remain recoverable.
