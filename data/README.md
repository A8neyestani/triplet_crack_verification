# Dataset

`triplet_crack_dataset.zip` is the prepared data used by this repository. It
contains the following directory after extraction:

- `anchor/`: 20,000 source crack images.
- `positive/`: 20,000 deterministic transformations of the matching anchors.

The archive is stored with Git LFS. After cloning, extract it from the
repository root with:

```bash
python -c "import zipfile; zipfile.ZipFile('data/triplet_crack_dataset.zip').extractall('data')"
```

The positive images are generated by the repository's preprocessing script
using rotation, shearing, and a brightness adjustment. They are training
augmentations, not longitudinal observations of the same physical crack. The
training script samples negatives from the available anchor/positive pool.

## Source and attribution

The source images come from **Concrete Crack Images for Classification** by
Çağlar Fırat Özgenel, published through Mendeley Data:

- Version 2: <https://data.mendeley.com/datasets/5y9wdsg2zt/2>
- DOI: [10.17632/5y9wdsg2zt.2](https://doi.org/10.17632/5y9wdsg2zt.2)
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

The original dataset contains 40,000 RGB images (20,000 positive and 20,000
negative) at 227 × 227 pixels. This repository includes the crack-image subset
used as anchors plus the generated positive counterparts. If you redistribute
or reuse the images, keep the attribution above and comply with the CC BY 4.0
terms.

## Recreating the positive directory

If you start with the source crack images in `anchor/`, regenerate the prepared
positives with:

```bash
python src/prepare_triplet_dataset.py \
  --anchor-dir data/triplet_crack_dataset/anchor \
  --positive-dir data/triplet_crack_dataset/positive
```

The archive is provided for convenience and exact reproduction of the included
training setup.
